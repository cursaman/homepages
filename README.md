# 처음 만드는 AI 웹사이트

AI를 활용하여 아이디어부터 실제 배포까지 10단계로 경험하는 초보자용 학습 사이트입니다.

## 주요 기능
- 10 STEP 학습
- Prompt 복사
- 실습 Checklist
- STEP 완료
- 학습 진행률
- localStorage 저장
- 이어서 학습하기
- 반응형 UI

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`

## Build

```bash
npm run build
```
